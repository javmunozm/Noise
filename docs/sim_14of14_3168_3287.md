# 14/14 simulation — tickets needed per series, last 120 series (3168–3287)

Run 2026-10-04 in a cloud session. For each series, distinct tickets are played one at a time until one matches **any** of the series' 7 events exactly; the table records that count ("tries").

## Method

- **System (CB pair):** ticket A sampled with a tilt toward the CondScore ranking (z-scored CondScore × 0.5 + Gumbel noise; history strictly before the series), then ticket B = A's contrarian (the 11 numbers A left out + A's 3 weakest by CondScore), emitted as pairs A, B, A, B, … — the contrarian rule in `bsadb_update.py`. Duplicates are skipped, so tries = distinct tickets.
- **Random:** uniform random distinct tickets.
- Seeds are fixed per series (system: `default_rng(sid)`; random: `default_rng(10000 + sid)`), so every count is reproducible.
- 3286 and 3287 use user-supplied results (not yet ingested via `add_series.py`). All 120 series have 7 events.
- Theory for any ticket order (independent draws): mean (4,457,400+1)/8 = 557,175 tries; median 420,228.
